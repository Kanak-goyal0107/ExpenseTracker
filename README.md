BizTrack – AI Powered Expense Tracker App (Flutter + Firebase + Gemini AI)

An intelligent and modern Expense Tracker App built using Flutter and Firebase that helps users manage their daily income and expenses efficiently. The app provides real-time expense tracking, financial analytics, AI-generated financial insights, dark mode support, and interactive charts for better money management.



Features

- Real-time Expense & Income Tracking
- Add and Delete Transactions Dynamically
- Firebase Firestore Integration
- AI-powered Financial Insights using Gemini API
- Interactive Expense Visualization Charts
- Dark Mode Support
- Dynamic Balance Calculation
- Beautiful Gradient UI Design
- Splash Screen
- Responsive & User-Friendly Interface
- Real-Time Database Updates



Tools & Technologies

- Flutter

- Firebase Core
